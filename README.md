## About this project

This is an unofficial, independently maintained build of Litefin that adds continuous fast-forward and rewind with Jellyfin trickplay previews.

**Features**
- Continuous 4×, 8×, 16× and 32× seeking
- Remote-control FF/RWD support
- Visual timeline previews
- Universal ARM32/ARM64 Android APK

**Maintenance and support**

This is a personal-use project made publicly available for anyone who finds it useful. Updates are provided on a best-effort basis, without guaranteed compatibility, maintenance, or technical support.
